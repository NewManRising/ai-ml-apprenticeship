## Current Status
The leadgen MVP is done. It is not deployed and was meant more as a practice to build upon. 

LeadGen MVP v0.1 currently includes:

- FastAPI backend
- Yelp API integration
- Filtering and scoring
- Excel export
- Streamlit frontend
- Frontend ↔ backend communication
